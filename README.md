OhmMate

OhmMate is a Python-based electrical calculator designed to perform basic electrical calculations using Ohm's Law.

Features

- Voltage calculation
- Current calculation
- Resistance calculation
- Electrical power calculation
- Series resistance calculation
- Parallel resistance calculation
- Interactive menu with a continuous calculation loop
- Basic input validation

Technologies Used

- Python 3 ,Pydroid 

How to Run

1. Download or clone this repository.
2. Open the project using a Python interpreter.
3. Run "ohmmate.py".
